# Dye my Roots HEX
## Instructions

**Help Ms Kelly to dye some faded out hair!!!**

Use the **arcade controls** or **Keyboard** to enter the exact hex color that the customer desires and earn some bucks :D

- **LEFT / RIGHT** — move between the six color digits
- **UP / DOWN** — change the selected digit (0-9, A-F)
- **ENTER / A button** — submit the color and dye the hair
- **ESC / B button** — cancel

The same character-roller input is used to enter your name on the title
screen, just like a classic arcade leaderboard. Keyboard arrows/WASD/Enter
also work as a fallback for desktop testing.

Your name is remembered between sessions, and your best earnings are kept on
the top-10 leaderboard shown on the title screen (saved to `user://save.json`).
